Web小説を音声で読み上げる Chrome 拡張機能のセットアップ手順

はじめに — 音声合成エンジンが別途必要です

この拡張機能は、パソコン上で動く音声合成ソフト（VOICEVOX または COEIROINK）と連携して動きます。 どちらも無償ですが、拡張機能とは別にインストールし、読み上げ中は起動しておく必要があります。 インストーラは 1GB を超える大きさです。

エンジンを入れずに試したい場合は、Chrome 内蔵の音声（Chrome TTS）でも動きます。インストールは不要ですが、音質は大きく劣ります。

どちらのエンジンを選ぶか

VOICEVOXCOEIROINKChrome TTS
インストール必要必要不要
音質高い高い低い
話者数多い（40キャラ以上）やや少なめ数種類
動作の軽さ軽快やや重い最も軽い
費用無償無償無償

迷ったら VOICEVOX をおすすめします。話者が多いので、地の文・会話文・心の声に別々の声を割り当てる機能を活かせます。動作も軽快です。

なお、この拡張機能は音声を再生するだけで、保存も配布もしません。 各エンジンのキャラクター規約は主に「生成した音声を公開・配布する場合」の制約なので、 自分で聴くだけの読み上げであれば、クレジット表記なども不要です。

1. 音声合成エンジンを入れる

VOICEVOX を使う場合

  1. VOICEVOX 公式サイトからインストーラをダウンロードして実行します。
  2. GPU がない場合は「CPU版」を選びます。動作します。
  3. インストール後、VOICEVOX を起動します。起動しっぱなしにしておいてください。

正しく起動していれば、ブラウザで http://localhost:50021/version を開いたときにバージョン番号が表示されます。

COEIROINK を使う場合

  1. COEIROINK 公式サイトからダウンロードして展開・実行します。
  2. 起動したままにしておきます。

確認用URLは http://localhost:50032/ です。

2. 拡張機能を設定する

  1. Chrome のツールバーにある拡張機能のアイコンをクリックして、設定パネルを開きます。
  2. 上部のタブから、使うエンジン（VOICEVOX / COEIROINK / Chrome）を選びます。
  3. エンジンが起動していれば「接続中 ✓」と表示され、話者の一覧が出ます。
  4. 好みの話者とスタイルを選びます。

最後に「設定を保存」ボタンを必ず押してください。 タブを切り替えて話者一覧が表示されただけでは、設定は反映されていません。 ここを押し忘れると、読み上げ開始時に「接続できません」というエラーになります。 最もよくあるつまずきです。

設定パネルでは、速度・音量・ピッチ・抑揚のほか、 会話文や心の声に別の声を割り当てることもできます（VOICEVOX / COEIROINK のみ）。

3. 読み上げる

  1. 対応サイト（ハーメルン、カクヨム、小説家になろう、ノクターンノベルズ、アルファポリス）で小説の本文ページを開きます。
  2. 画面右下に操作パネルが表示されます。
  3. ▶ ボタンで読み上げが始まります。

操作パネルからは、段落の前後移動・前話/次話への移動・速度調整ができます。 ⚙ ボタンを押すと、本文クリックでその段落へ移動する設定や、最終段落まで読んだら自動で次話へ進む設定などが変更できます。

うまくいかないとき

「接続できません」と表示される / 話者一覧が空になる

次の順に確認してください。

  1. エンジンが起動しているか。VOICEVOX / COEIROINK のウィンドウが開いたままか確認します。
  2. 確認用URLが開けるか。VOICEVOX なら http://localhost:50021/version、COEIROINK なら http://localhost:50032/ をブラウザで開きます。ここが開けなければ、エンジン側の問題です。
  3. 「設定を保存」を押したか。下記の項目を参照してください。
設定したはずなのに、再生すると「接続できません」になる

「設定を保存」ボタンの押し忘れがほとんどです。

たとえば以前 COEIROINK を使っていて、あとから VOICEVOX のタブに切り替えた場合。 タブ上には VOICEVOX の話者一覧が表示されますが、保存ボタンを押していなければ、 実際に保存されているのは以前の COEIROINK の設定のままです。 その状態で再生すると、起動していない COEIROINK へ接続しにいって失敗します。

エラーメッセージに表示されているエンジン名を見てください。 自分が選んだつもりのエンジンと違う名前が出ていれば、保存されていないということです。

エンジン側で CORS の設定は必要？

不要です。設定を変更しないでください。

VOICEVOX の設定画面には「CORS Policy Mode」という項目がありますが、 この拡張機能を使うために変更する必要はありません。初期値（localapps）のままで動作します。

接続できない場合、原因はほぼ「エンジンが起動していない」か「設定を保存していない」のどちらかです。 CORS 設定を all に変えると、他のソフトからもエンジンにアクセスできる状態になるため、変更は勧めません。

読み上げの声が途中で変わる / 一部が読み飛ばされる

会話文（「」で囲まれた部分）や心の声（（）で囲まれた部分）に別の声を割り当てる機能が有効になっています。 設定パネルの「会話文1の声」「会話文2の声」「心の声」を「全般と同じ」に戻すと、すべて同じ声になります。

また、絵文字や特殊記号は音声合成できないため取り除かれます。 ごく一部の文が合成に失敗した場合は、その部分だけ読み飛ばして再生を続けます。
